# nextDays

A local desktop calendar application for Windows with event management and system notifications.

## About

nextDays is a personal calendar designed to help users organize their daily activities, manage events and receive timely reminders.

The application works locally on a Windows computer and does not require cloud services or an internet connection for its core functionality.

## Features

- Monthly calendar view
- Event creation and editing
- Event descriptions
- Customizable reminders
- Windows desktop notifications
- Local data storage
- Event management

## Technology Stack

- Python
- PySide6
- SQLite
- Windows Toast Notifications
- Git and GitHub
